# Synthetic data

Synthetic samples are vectors in the anonymised PCA feature space (V1-V28) plus Amount, generated by a VAE trained on normal transactions. They are not real or interpretable transaction records: the original features and PCA loadings were never published, so rows cannot be mapped to merchants, cards, places or customers. No fraud label is attached. Source data: Credit Card Fraud Detection, ULB MLG / Worldline (Kaggle mlg-ulb/creditcardfraud), ODbL 1.0 / DbCL 1.0; Dal Pozzolo et al., CIDM 2015.

Each CSV has columns `V1`–`V28` and `Amount`. It has no `Class` and no `Time` column. The matching `.meta.json` records the model checkpoint, seed, sampling temperature and file hash.
